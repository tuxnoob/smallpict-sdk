# SmallPict Ruby SDK

Official Ruby gem for the [SmallPict Image Optimization API](https://smallpict.tuxnoob.com).

> ⚠️ **Development Scaffold (Phase 0):** This gem is currently being scaffolded under Phase 0. Full implementation begins in **Phase 3.1**.

## Target Features
- Ruby 3.0+ compatibility with Faraday HTTP connection pooling.
- Optional Ruby on Rails / ActiveStorage image variant processor.
- Custom exception hierarchy with secret redaction.
